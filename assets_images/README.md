# Images

Upload reference images into this folder.

Recommended:

- Use `.jpg` or `.webp` for smaller files.
- Resize large images to about 1200-1600px wide before uploading.
- Use simple lowercase filenames, for example `glass-citrus-study.jpg`.
- In `data/prompts.json`, reference the image as `assets_images/glass-citrus-study.jpg`.
